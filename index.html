•Turni squadre — modello ciclico

Ogni squadra segue un ciclo di 3 settimane: fase 1 = lun-mer 2°turno, gio-ven 1°turno · fase 2 = lun-mer 1°turno, gio-ven 2°turno · fase 3 = lun-ven 3°turno (il primo venerdì del mese in fase 3 è riposo compensativo; un eventuale secondo venerdì nello stesso mese resta lavorativo). Il modello si usa solo quando il file caricato non copre più quella data.

Eccezioni manuali per la settimana aperta

Se per questa settimana specifica un turno differisce dal modello (es. cambio concordato), correggilo qui: ha sempre la priorità sul calcolo automatico.
